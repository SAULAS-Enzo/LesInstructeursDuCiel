# Les Instructeurs du Ciel

## Application Web

### Commandes importantes

#### Lancer le frontend

Dans le dossier ```./frontend/``` lancer la commande ```npm dev run```
Puis sur un navigateur, taper l'url : http://localhost:5173

#### Lancer le backend
A la racine du projet, lancer la commande ```mvnw spring-boot:run```

#### Créer la javadoc

N'importe ou dans l'arboresence : ```mvnw javadoc:javadoc```

## Cloner de dépôt :

/!\ Attention
 - Créer un dossier config/
 - Ajouter vôtre identifiant et mot de passe pour accéder à votre base de données
